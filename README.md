# Hospital Management System :-

A Java-based Hospital Management System
using JDBC and MySQL.

## Technologies
- Java
- JDBC
- MySQL

## Features
- Patient Registration
- View Patients
- View Doctors
- Book Appointments

## Project Structure
- Doctor.java
- Patient.java
- HospitalManagementSystem.java

## Future Enhancements
- User Authentication
- Billing Management
- Appointment Management
